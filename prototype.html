Moonrope Documentation
Adam C · updated today

Moonrope is the internal API gateway that sits between client integrations and the core sync engine. This page documents the auth handshake and rate-limit behaviour.

Authentication

Clients exchange a long-lived key for a short-lived token via POST /oauth/token. Tokens expire after 15 minutes and refresh through the same endpoint.

  • Keys are per-tenant, scoped to a single project
  • Refresh is idempotent — or should be (see ticket #3)

Rate limits

Default is 600 requests/minute per tenant, burstable to 1000. Exceeding returns 429 with a Retry-After header.
