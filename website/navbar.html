Navbar

Application chrome, project context, and tabs use semantic current states.

Primary navigation only

Use the navbar by itself on workspace-level screens. The contextual subnav is optional and should not be rendered when there is no project or section context.

K Kioto

Actions

Use navbar-actions to align search, buttons, and button-like links at the end of the navbar. Choose ordinary button variants explicitly; the navbar does not change their colors.
