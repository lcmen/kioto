Forms

Compact form controls include visible focus, disabled, help, and invalid states with responsive layout helpers.

Project form

Associate every label and message with its control. Use aria-invalid and aria-describedby for validation.

Use letters, numbers, and hyphens only.

Visible to everyone in the project.

<div class="form-group"> <label class="form-label" for="name">Project name</label> <input class="form-input" id="name" aria-describedby="name-help"> <p class="form-help" id="name-help">Visible to the team.</p> </div>

Checkboxes and radio buttons

Group related choices with a fieldset and legend. Use checkboxes for independent options and radio buttons for one choice from a set.

Notifications

Choose any notifications you want to receive.

Default view
<fieldset class="form-group"> <legend class="form-label">Default view</legend> <label class="form-choice"> <input class="form-radio" type="radio" name="view" checked> List </label> <label class="form-choice"> <input class="form-radio" type="radio" name="view"> Calendar </label> </fieldset>

Control states

Native disabled attributes and semantic validation attributes provide the visual state without JavaScript-specific classes.

Correct this value before saving.

<input class="form-input" disabled> <input class="form-input" aria-invalid="true" aria-describedby="field-error"> <p class="form-error" id="field-error">Correct this value.</p>

Compact and inline

Add form-compact to a parent to reduce its input, select, and textarea density.
