Buttons

Combine btn with one visual variant and an optional size or layout modifier.

Variants

Primary actions should be scarce. Secondary and ghost buttons support the workflow, dark suits darker chrome, and danger is reserved for destructive operations. Placeholder buttons use the prototype’s dashed empty-state treatment.

<button class="btn btn-primary">Create project</button> <button class="btn btn-secondary">Cancel</button> <button class="btn btn-danger">Delete</button> <button class="btn btn-dark">Dark</button> <button class="btn btn-ghost">Ghost</button> <button class="btn btn-placeholder">+ Placeholder</button>

Sizes and icon buttons

Icon-only buttons require an accessible name. btn-full fills its containing width.

<button class="btn btn-primary btn-sm">Small</button> <button class="btn btn-primary btn-lg">Large</button> <button class="btn btn-secondary btn-icon" aria-label="Add item">+</button> <button class="btn btn-primary btn-full">Continue</button>

Native disabled and aria-disabled="true" states are styled. Prevent activation yourself when using aria-disabled on links.
