Button groups

Button groups join related choices into one compact control.

Selected state

Use aria-selected for tab-like view switching or aria-pressed for toggle buttons.

<div class="btn-group" role="tablist"> <button class="btn-group-item" aria-selected="true">List</button> <button class="btn-group-item" aria-selected="false">Calendar</button> </div>
