Kioto UI Toolkit

A Foundry-inspired, CSS-only component toolkit for dense, practical web applications. Kioto gives Tailwind CSS v4 projects a semantic class layer that remains easy to override.

Install from source

Import Kioto after Tailwind and the forms plugin. Consumers may redefine Kioto’s theme tokens in a later @theme block.

@import "tailwindcss"; @plugin "@tailwindcss/forms" { strategy: base } @import "./kioto.css";

Reference

Components are composable: combine a base class with a variant and optional size. Interaction state is represented with native attributes.
